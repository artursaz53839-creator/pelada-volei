# Vôlei CCV

App para organizar a pelada de vôlei: lista de presença com horário de chegada, times montados por ordem de chegada (Time 1, 2, 3…), fila automática (quem perde vai pro fim, e os primeiros do time que perdeu completam o próximo time incompleto), placar e ranking.

- **Link único:** https://volei-ccv.vercel.app/. Todo mundo acompanha ao vivo; administradores entram pelo 🔒 no topo com o próprio PIN.
- **Dados:** Supabase (projeto `pelada-volei`). O dono adiciona e remove administradores pelo app.
